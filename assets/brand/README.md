# MONO brand assets

Varianti operative normalizzate per il sito MONO.

- `mono-logo-primary.svg` - logo principale su fondo chiaro.
- `mono-logo-light.svg` - logo chiaro/oro per hero scure.
- `mono-logo-mono.svg` - variante monocromatica antracite.
- `mono-logo-champagne.svg` - variante premium su fondo scuro.
- `mono-convivium-primary.svg` - Convivium terracotta/antracite su chiaro.
- `mono-convivium-light.svg` - Convivium light per fondi scuri.

Gli originali in root restano come sorgente storica; le pagine usano le varianti in questa cartella.
